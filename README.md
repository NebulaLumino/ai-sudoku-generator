# AI Sudoku Generator

An AI-powered AI Sudoku Generator tool built with Next.js 16, TypeScript, Tailwind CSS, and DeepSeek API.

## Features
- Generate AI Sudoku Generator content instantly
- Dark gradient UI
- Powered by DeepSeek AI
- Fully responsive

## Setup
```bash
export OPENAI_API_KEY=your_deepseek_api_key
npm install && npm run dev
```
